# Tech Stack

## Engine

- **Godot 4** — Game engine for rendering, input, scene management, and hex grid implementation

## Scripting

- **GDScript** — All game logic, GURPS rules implementation, UI, and tooling

## Data

- **GCS/GCA file import** — Character data sourced from GURPS Character Sheet (GCS) and GURPS Character Assistant (GCA) file formats
